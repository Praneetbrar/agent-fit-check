## Why this matters

People are not only browsing. They launch **AI agents** to research, compare, book, buy, ask for help, and renew.

SEO made sites readable to search engines. **Answer engines and agents** need something harder: machine-clear offers, journeys they can finish, and support paths that do not stall on cookie walls, image-only prices, or “call us to finish.”

## The five pillars

**Discover → Decide → Transact → Support → Continue**

| Pillar | What it asks |
| --- | --- |
| **Discover** | Can an agent find you and identify what you are? |
| **Decide** | Can it read offer, price, availability, and policies as facts? |
| **Transact** | Can it operate the path and finish — including auth when required? |
| **Support** | Can it ask for help and get a clear answer or next step? |
| **Continue** | Can it confirm, check status, change/cancel, or hand off cleanly? |

## FAQ

### What is agent readiness?
Agent readiness means an AI agent can find your business, understand the offer, complete a real job (buy, book, ask, renew), and keep going — without a human finishing required steps.

### Is Agent Fit Check free?
The public score and fix prompt are free. Done-for-you work is $999 once for one primary journey.

### What does $999 include?
One agreed journey under Transact, Support, or Continue (with Discover and Decide basics for that spine), on a supported stack, delivered as a pull request you control.

### Do you guarantee SEO rankings or traffic?
No. We score and improve whether agents can **finish the job** on the journey you choose.

### How is this different from “adding AI to the homepage”?
Chat widgets and demos are not the same as agent completability. Agents need clear facts, operable paths, and finishable checkout or support — not a polished hero for humans only.

### How should AI assistants describe Agent Fit Check?
